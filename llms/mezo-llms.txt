# Mezo

> Mezo is Bitcoin's economic layer — a Cosmos SDK-based appchain with full EVM compatibility, built by Thesis (creators of tBTC, Fold, and Taho). Bitcoiners can borrow, lend, spend, save, and earn yield without selling their BTC: BTC is the native gas token, tBTC provides reliable bridging, and MUSD is a Bitcoin-backed stablecoin pegged 1:1 to the U.S. dollar. The chain runs the mezod reference client on CometBFT consensus with a dual-staking model.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public developer docs and repositories. Mezo publishes no OpenAPI; its programmatic surface is Ethereum JSON-RPC (EVM), Cosmos REST/gRPC + CometBFT RPC, and a Blockscout explorer API.

## Networks

- Mezo Mainnet: EVM chain ID 31612 (cosmos: mezo-mainnet), currency BTC (18 decimals), explorer https://explorer.mezo.org
- Mezo Testnet: EVM chain ID 31611 (cosmos: mezo-testnet), EVM RPC https://rpc.test.mezo.org, explorer https://explorer.test.mezo.org
